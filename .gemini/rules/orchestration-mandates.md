# Orchestration and Execution Mandates

1. **Centralized Execution:** The file `src/orchestrator.py` is the SINGLE entry point for running data pipelines and training modules. Do not run individual ETL or training scripts directly in production.
2. **Integrity via Tests:** The orchestrator MUST run the test suite (`pytest`) before any data processing or model training occurs. If tests fail, the pipeline must halt immediately.
3. **Idempotency Control & Modularity:** The orchestrator and underlying scripts must verify if output artifacts exist to avoid re-running expensive tasks. **CRITICAL:** Idempotency checks must be completely decoupled for Data (Parquet/CSV) and Visuals (PNGs). If visuals fail, the data should not be skipped incorrectly on the next run. Scripts must skip execution of isolated components if they already exist, unless `--force` is used.
4. **Clean Executions:** The orchestrator must support a `--clean` flag that strictly deletes all `bronze` and `visuales` output directories before running, ensuring a completely pure execution environment.
5. **Continuous Pipeline:** The orchestrator functions as a continuous pipeline, running tasks sequentially from start to finish.
6. **Hardware Constraints & Dataset Downsampling:** Deep Learning models using `NeuralForecast` must dynamically subset the `train_df` based on the strategy (`toy`: 2 plants, `half`: 1 year history, `total`: 2 years history) to avoid `CUDA Out of Memory` issues during TimeSeriesDataset tensor allocation on standard GPUs (6GB VRAM).
7. **Cross-Validation Leakage Prevention:** `val_subset` in tuning phases MUST be relative to each plant's maximum timestamp (e.g. `groupby('unique_id')['ds'].max()`) instead of the global maximum, ensuring that `predict()` receives completely contiguous dates in `futr_df` avoiding 'Missing combinations' errors.
8. **Memory Leak Prevention:** PyTorch Lightning objects (`NeuralForecast`, models) must be explicitly destroyed using `del nf`, `del model_obj`, `gc.collect()`, and `torch.cuda.empty_cache()` inside `finally` blocks to release reserved unallocated memory across sequential optuna trials.
9. **Quantile Evaluation:** The loss function `MQLoss` must strictly use `level=[90]` to generate accurate 90% confidence intervals (`lo-90` and `hi-90`). Using `quantiles=[0.1, 0.5, 0.9]` produces an 80% CI which breaks downstream visualizers and metric calculations.
