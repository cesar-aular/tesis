# Documentation Standards

1. **Pre-Planning Changes:** Todos los cambios arquitectónicos, estructurales o significativos en el código DEBEN planificarse en [docs/plan.md](file:///c:/Users/cesar/Desktop/code/tesis-final/docs/plan.md) antes de su ejecución.
2. **Task Tracking:** Una vez que un plan es aprobado, los pasos de ejecución deben desglosarse y rastrearse en [docs/tasks.md](file:///c:/Users/cesar/Desktop/code/tesis-final/docs/tasks.md) utilizando un formato de lista de verificación (checklist).
3. **Change Logging:** Cada plan completado o cambio significativo debe documentarse en [docs/changelog.md](file:///c:/Users/cesar/Desktop/code/tesis-final/docs/changelog.md) para mantener un registro histórico de las acciones realizadas en el proyecto.
4. **Workspace Confinement:** Las comprobaciones (scripts de prueba, análisis exploratorios) y la creación de cualquier archivo DEBEN hacerse estrictamente dentro del directorio del proyecto principal. No se permite usar directorios de scratch o alternos.
