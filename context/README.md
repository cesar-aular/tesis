# context/ — Material de referencia del proyecto de título

Insumos y material de apoyo (no forman parte del pipeline de datos). Organizado por tema:

| Carpeta | Contenido |
|---------|-----------|
| [`anteproyecto/`](anteproyecto/) | Anteproyecto aprobado: `anteproyecto.pdf` y su transcripción `anteproyecto_text.txt` (fuente de contexto para el trabajo). |
| [`evaluacion-profesor/`](evaluacion-profesor/) | Rúbrica y evaluación del informe por el profesor guía (feedback que originó las últimas correcciones). |
| [`plantilla-beamer-ucm/`](plantilla-beamer-ucm/) | Plantilla oficial de presentación de la UCM: tema `QUT.sty`, ejemplo `presentacion.tex`, `ref.bib`, `img/logoUCM.png` y su `README.md`. Base de estilo de `latex-tesis/defensa.tex`. |
| [`referencias-diseno/`](referencias-diseno/) | Referencias visuales de diseño (p. ej. `medallion-architecture.png`, estilo de linaje de datos usado en los diagramas de arquitectura). |
